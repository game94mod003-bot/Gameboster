# Aether

Android VPN app (WARP over MASQUE / CONNECT-IP on HTTP/2, IPv4 + IPv6).

## Build with GitHub
1. Upload all files of this project to the root of a GitHub repository.
2. Open the **Actions** tab, wait for **Build Aether APK**, then download the **Aether-APK** artifact (app-debug.apk).

## Usage
1. Scan: finds the fastest Cloudflare endpoint.
2. Get WARP key: registers an account.
3. Connect: starts the tunnel; shows live status, stability and exit IP.
